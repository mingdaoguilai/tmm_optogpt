# 第四版第四阶段：精修工作流（0.4.3）

第三阶段已经提供生成后的自动精修。本阶段补齐“编辑→生成→精修→比较→采用→复算→保存/导出”的可追溯交互，不另加优化算法。

## 端到端操作

1. 在逆向页编辑光谱、设计要求和工艺边界；需要时打开连续厚度精修。
2. 生成任务在后台运行；只要有已验证的候选就同步到共享结果。可以用“比较 / 采用已保存候选”进入比较页，运行中排名仍可能变化。取消、失败或连接中断不会清空已发布结果。
3. 比较页最多选择4组，叠加初值虚线/当前实线，按同一网格查看平均违反误差、容差前MAE、最大考核偏差、最大超差及加权达标比例。局部波段也提供前后指标。
4. 点“按原网格复算前后结果”时，从实际浮点层厚重新计算，不从原token重建。复算后的指标保存回候选，纳入设计包。旧项目缺少的初值指标可由这一操作补齐，不用当前结果冒充初值。
5. 可分别“采用当前结果并去正向页”或“采用精修初值”。比较页采用前会先复算（同一候选未改变时可复用本轮复算）；逆向页的快捷采用使用当前已验证候选。采用只复制所选结构，不修改保存的初值和精修候选。
6. 正向页显示采用来源及固定的目标/要求快照。“按原考核网格复核当前膜系”用实际当前厚度、入射角、偏振及基底等设置重新TMM计算，保留原精确波段边界和非均匀采样点。
7. 保存项目或“导出完整设计包 JSON”，重新打开后逆向页和比较页显示同一批候选，采用来源和复核记录一起恢复。也可分别导出当前厚度、初值厚度、当前光谱以及正向复核光谱CSV；厚度用完整浮点数写出，界面显示位数不改变导出精度。

## 指标口径

“最大考核偏差”是启用通道/波段中最大的容差前误差：匹配曲线取绝对偏差，至少/至多要求取单侧未满足误差。未考核区间不参与。“最大超差”进一步扣除允许容差；两者不等同于全谱最大R/T误差。达标比例按有效点权重统计，不是连续波长上逐点达标的证明。

全谱R/T MAE仍保存为参考指标。初值/当前结果只在同一考核网格和同一要求下比较；本阶段不把正向常规均匀网格的图表误差直接作为精修收益。模型10 nm输入分辨率不变。

## 修改后的失效标记

采用快照保留所选版本、实际候选、目标、要求和原仿真条件。若编辑厚度/材料、角度/偏振、基底或常规波长设置，会提示已修改；仍可对原目标复核，但不能把它称作对原候选的无变化重复复算。只改常规显示网格也会标记设置变动，原评分网格本身不变。

复核记录包含完整仿真请求、目标/要求和评分网格。任一部分与当前设置不一致，就视为历史记录；不会开放“本次复核”CSV/JSON导出。常规正向CSV在请求变动、计算中或失败时同样不导出旧成绩。异步返回结果必须匹配当前上下文，避免导入新项目或换候选后旧响应覆盖新状态。

## 保存格式和接口

项目schema 4接受schema 1/2/3。新增`adopted_candidate`与`forward_verification`；候选设计快照补充`search_settings`、`search_summary`、`job_id`和`job_status`。项目、设计包和浏览器草稿保存同一完整结构。

- `POST /api/candidates/review`：对实际当前层和保存的精修初值按当前候选原网格复算。无需加载OptoGPT权重；旧项目可离线于模型完成复核。
- `POST /api/candidates/verify`：用指定仿真条件在原网格复核，并返回光谱、指标及完整请求快照。

复核网格必须覆盖400–1100 nm、严格递增且有限，最多12000点。采用快照校验实际厚度与仿真层一致；复核结果校验光谱长度及采样网格一致。

工艺量化、厚度扰动鲁棒性、多目标多种子基准、50/100层模型扩展均不在本阶段实现范围内。

## 验收

后端53项、前端18项测试通过；生产构建通过。新增测试包括实际浮点厚度与token区分、原始/当前采用、非均匀网格复现、角度偏振变动重算、最大偏差与超差口径、迟到结果保护、CSV精度及schema 1–4往返兼容。

本地浏览器使用真实checkpoint完成编辑高斯目标→200次小预算生成（Top-k=1、最大1层，仅作为流程验收）→20次TMM精修→比较→采用当前结果→原网格复核→保存→采用初值→重开项目→核对逆向页共享候选。得到的模型token为MgF2_240，实际精修厚度222.9448996157717 nm；采用/保存恢复的仍是这一浮点厚度，初值采用则为240 nm。725点原网格复核平均违反误差与采用基线一致（0.13477885250742194），修改入射角后旧复核导出被禁用。单层结果并未达到该目标，不以流程跑通冒充自由目标精度达标。
