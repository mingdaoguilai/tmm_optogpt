# 第四版第一阶段：目标光谱编辑（0.4.0）

本阶段完成下一版计划中的目标输入升级。沿用第三版的模型与搜索，不包含厚度精修、缺失通道 mask、波段容差或自由手绘笔刷。

## 使用

从原快捷方式或仓库根目录的 `start_workbench.cmd` 启动，确认界面显示 OptiForge · V4 和 0.4.0，再进入逆向设计。

1. 选择编辑 R 或 T。拖动控制点，或者在图内双击添加控制点。选中点后可数值修改波长/幅值，使用方向键微调、Delete 删除。400 和 1100 nm 两个端点可以改变幅值，但不能删除或改变波长。
2. 选择折线或保形平滑。平滑使用分段三次 Hermite 保形插值，避免普通样条在峰谷附近过冲。
3. 根据需要开启“无吸收联动（R+T=1）”。开启会按当前编辑通道重新计算另一条曲线，代表明确的无吸收假设；关闭后两通道独立，可描述吸收光谱。生成时仍需完整 R/T 数据。
4. 使用高斯峰、高斯陷波、带通、长波通边缘组件，调整中心、宽度、低/高幅值，再点“应用光谱组件”。可以替换当前通道，或以峰取高值、陷波取低值叠加到已有曲线，建立多峰/多谷。高斯宽度为半高全宽，边缘过渡宽度为10–90%区间；带通宽度为两名义边缘之间的距离，过渡区重叠时不保证实际达到指定高幅值。
5. 在“模板、CSV导入与导出”中上传或粘贴 `wavelength_nm,R,T` 数据。至少两行，覆盖400–1100 nm，可不等间隔；会排序，但重复波长、空值和坏行会报错，不会静默跳过。支持正向导出CSV的额外A列，按前三列解析。最多2000个原始数据点。
6. 所有目标编辑支持最多30步撤销/重做；一次完整拖拽只记录一个操作。刷新后恢复当前草稿，撤销历史不跨刷新保留。
7. 顶部保存项目会记录控制点、连接方式、联动模式、组件参数和原始导入数据；打开后仍可编辑。也可以分别导出编辑后的CSV和原始目标CSV。

## 光谱与模型输入

绘图/提交目标使用1 nm展示网格，同时保留不落在整数网格上的控制点位置；这不代表增加模型本身的分辨率。原始导入曲线在项目中单独保存，包括模型范围外的数据。编辑区只覆盖400–1100 nm。

黄色虚线显示当前通道实际送入模型的10 nm采样点连接线。当用户曲线与模型网格的重建曲线存在超过2个百分点的偏差时，显示细节损失提示。它是重采样差异提示，不是可实现性或设计精度证明。

R/T必须有限且位于0–1。独立编辑时出现R+T>1的草稿可保存和修正，但“生成候选”禁用，后端也拒绝这类被动光谱输入。任务对提交时目标取快照，后续编辑不改变已生成候选的评分目标。

## 项目兼容

项目 schema_version 升为2，新增 `target_editor`，内部编辑格式版本为1。旧schema 1项目和旧草稿自动迁移为控制点编辑；既有候选及其生成目标继续保留。当前 `target` 字段仍提供普通波长/R/T数组，后端接口与模型调用方式不变。

项目加载以已验证的 `target_editor` 重新构建当前目标，防止控制点与缓存数组不一致。原先没有编辑信息的项目按目标数据创建控制点，默认折线。只有R+T在所有原始点上等于1时，迁移默认开启联动。

- 实际将CSV自定义目标（4个R控制点、3个T控制点；701个展示采样点）提交给checkpoint，完成12次抽样、7个唯一结构TMM验证，返回2组候选。这验证衔接可用，不代表自由目标的普遍反演精度已改善。

前端测试运行 `npm test`，构建运行 `npm run build`；后端运行 `python -m unittest discover -s tests -v`。
