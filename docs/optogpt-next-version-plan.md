# 下一版 OptoGPT：自由光谱编辑与候选厚度精修（讨论稿）

状态：第一部分目标输入已在 v0.4.0 实现控制点编辑、参数化组件、CSV 后编辑与保存恢复。详见 `optogpt-v4-inputs.md`。波段权重/容差、缺失通道目标、连续厚度精修和自由手绘仍为后续规划。

## 目标与完整流程

让用户通过控制点、曲线组件或 CSV 编辑描述光谱要求，OptoGPT 给出初始膜系，然后 TMM 驱动连续厚度优化。结果显示原始目标、模型输入、精修前后光谱、分波段误差和容差满足情况。目标是更自由地表达需求并改善可实现目标的拟合，不承诺任意手绘曲线都能实现。

## 1. 目标编辑器

优先实现控制点添加/拖动/删除，数值坐标修改，折线/保形平滑连接，撤销/重做，CSV 导入后编辑，以及高斯峰、陷波、带通和边缘组件。自由手绘为可选第二阶段：鼠标轨迹只覆盖经过的波段，重采样并提供可调平滑，避免把鼠标抖动当作设计要求。

编辑器保留用户原始目标与控制点，不用模型的 71 个采样点覆盖原始数据。并排或叠加显示重采样后的模型输入，标记可能在 10 nm 网格上消失的窄峰。默认 400–1100 nm，R/T 在 0–1 范围，检查有限数值、重复/无序波长及被动结构 R+T<=1。

每个通道支持启用/禁用、波段权重、允许误差及不关心区间。约束编辑与目标编辑分开：只画 T 时不得偷偷设 R=1-T；可以显式选择无吸收假设，或者根据当前膜系生成一条初始补全 R。未指定的值仅帮助 OptoGPT 提议结构，不进入真正精修的目标函数。UI 必须显示补全方式。缺失波段采取同样处理；当前 checkpoint 不直接支持 mask 条件输入。

## 2. 数据与接口

建议新增带版本的 TargetDesign，而不是扩充现有简单数组直到难以辨别语义。记录编辑模式、控制点/原始曲线、R/T 通道是否指定、关注波段、权重、容差和补全方式。派生出三组数据：用户目标、完整 142 维模型输入、带 mask/权重的精修目标。

既有 TargetSpectrum JSON/CSV 保持可读，项目格式新增版本及可选字段。一次任务对目标、补全、优化参数和仿真条件取快照；运行中修改曲线只改变下一次任务，不改变已有结果的评分口径。

## 3. 厚度精修

首先保持材料序列固定，优化每层的连续厚度。建议先选误差较低且材料序列不同的 5–10 个初始候选，防止预算花在相同拓扑的相似解上。使用 SciPy 的有界 least_squares 作为首个本地优化器，必要时从小扰动的厚度做多起点；遇到局部最优明显的案例，再增加 PSO/差分进化等全局搜索。

为每层设置工艺厚度上下限。初值由 OptoGPT 给出，默认限于 checkpoint 的厚度范围；若用户扩展范围，明确属于后处理搜索。材料替换、增删层和模型微调暂不加入首轮。

目标函数使用用户关注的通道与波段：误差位于容差内时残差为零，超出部分为 max(abs(实际-目标)-容差, 0)，再按波段/通道权重缩放后形成最小二乘残差。无容差模式则直接使用目标误差；可比较普通平方损失与 Huber 损失。缺失点权重为零。误差汇总与排序基于同一个目标快照。

缓存每种材料在评估网格上的 n/k，避免每次函数求值重新加载数据。优化使用浮点厚度与双精度 TMM；先以 5 nm 网格尝试，再以 1–2 nm 或过渡区加密网格复核。仅有粗目标时不得宣称新增了真实目标细节。用户目标若有更窄特征，需根据特征调整评估网格。

初期保留目前法向、非相干玻璃基底条件，防止自由输入同时扩展成新的模型训练问题。优化过程增加可取消、迭代/评估预算和明确进度。若精修没有改善，保留初始解并展示停止原因。

## 4. 输出与工艺验证

候选保存原始材料/厚度 token、精修后的浮点厚度、模型生成来源、优化收敛状态、评估次数与精修前后指标。实际仿真和采用候选使用精修厚度，不能继续依赖原 token 字符串还原结构。

默认显示关注波段的 MAE、最大偏差和容差满足比例，同时显示层数、总厚度与耗时。让用户分别查看连续厚度解和工艺量化解；按 1/2/5 nm 量化后重新计算，并可做有限邻域搜索，不能只显示连续解的成绩。厚度扰动/容差稳定性作为后续扩展。

## 5. 验收与开发顺序

第一步：先完成目标的数据定义与验证，测试控制点编辑、CSV往返、撤销、项目保存恢复、R/T冲突、缺失通道和模型输入预览。

第二步：完成固定材料序列的优化服务与任务状态。用已知膜系生成目标，验证相同材料序列但偏离厚度的初值能够减少光谱误差。由于逆问题多解，不要求恢复唯一原始厚度。

第三步：接入 v3 生成候选，完成“编辑目标→生成→精修→对比→采用→保存/导出”的端到端流程。分别保存初值和精修结果，支持失败/取消后保留已有结果。

第四步：用宽带增透、带通、双峰、非对称边缘、带吸收和只指定 T 等目标建立验证集。区分固定材料优化能力与完整反演能力；对比相同生成预算的 v3、下一版不精修、下一版精修，报告多种子的误差分布、耗时和达标比例。对不可实现的尖锐目标不伪报成功。

建议讨论的三个产品选择：先做精确控制点还是自由手绘；默认允许的材料与工艺厚度范围；“达标”的容差应采用用户指定值还是提供应用预设。目前建议控制点优先、显式工艺边界、用户可修改的容差预设。
