# 50–100层逆向设计：方案讨论，尚未实施

## 先区分三种能力

1. **正向计算50/100层**：现有TMM可处理可变层数，正向编辑器没有20层硬上限，但还没有据此建立100层的性能/稳定性验收标准。
2. **数值优化50/100层**：有实现机会，特别是固定材料顺序或周期/啁啾模板；这属于TMM驱动的长膜系优化，不等于现有OptoGPT已能直接生成100层。
3. **由目标直接生成任意50/100层材料与厚度序列**：需要长序列训练数据与训练/评测工作，不能仅改界面最大值就宣称完成。

上游论文将最大层数设为20。本仓库采用的Transformer代码使用可变序列与正弦位置编码，位置表默认可覆盖5000个位置；因此20不是注意力机制在数学上的硬上限，但训练范围、EOS分布和长序列的光学关联仍是主要限制。上游训练脚本的`max_len=22`也不能解释为22层。需要检查当前checkpoint及训练数据，而不是只看一个配置值。

## 三条路线

| 路线 | 可以做什么 | 主要限制 |
|---|---|---|
| 直接放开推理解码到50/100层 | 做不修改权重的研究对照，检查有效序列率、TMM误差和提前EOS | 训练外外推，无可靠性保证；强行屏蔽EOS只能迫使继续生成，不能补上长膜系设计能力，不适合作为默认产品能力 |
| 参数化长膜系＋TMM优化（优先考虑） | 周期/啁啾DBR、反射镜＋腔层、多个滤波段或匹配层；从较少参数得到50/100层 | 只覆盖指定结构家族；必须整栈联合计算，不能将独立优化的20层块直接拼起来就视为满足目标 |
| 长序列OptoGPT训练/微调 | 训练10–100层的材料/厚度生成，逐步加入21–40、41–60、61–100层数据，并保留短栈样本 | 数据、算力和长序列评测开销较大；先小规模验证迁移是否有效，再决定微调还是重训 |

这些是基于现有代码和物理模型提出的工程方案，不是已经验证的效果承诺。

## 推荐的渐进实现

第一步：先独立建设“长膜系数值设计”模式。让用户指定材料顺序或选择周期/啁啾、腔体/匹配层模板，输入重复次数、光学厚度、中心波长和可调范围。OptoGPT可提供≤20层种子/材料组合提示，但长结构需由明确的模板或拓扑搜索构造，再整体TMM验证。

第二步：参数降维和分块联合优化。先优化少量参数（周期数、各区段中心波长、啁啾率、厚度缩放等），再分块放开厚度，最后整体精修。加入总厚度、材料数量、最薄层、层间规则及制造可行性约束。先做50层基准，验证有效再扩展到100层。

第三步：改进数值计算。当前SciPy有限差分求雅可比，变量数增加会显著增加TMM调用；考虑解析/自动微分梯度、批量多起点、GPU向量化以及折射率缓存。厚层、强吸收、高反射长栈还要检查病态/溢出，用稳定散射矩阵或等效递推做交叉核验。不能以层数少时的单案例正确性代替100层验收。

第四步：若确有“完全自由的材料序列生成”需求，再建设长序列数据。除随机栈，也纳入周期、啁啾、腔体和优化后的高质量结构；按层数分层采样与评测，适配数据padding/mask、解码上限、EOS和全部约束编号。必要时加入期望层数条件。长序列推理缓存可减少重复计算，但本身不会改善训练外设计质量。

## 验收与取舍

比较相同目标下20/50/100层的误差、达标比例、总厚度、耗时以及制造厚度扰动后的稳定性。不能只要求“输出够100层”；也不能因为层数更多就默认精度更高。更高维逆问题常有多解，需要边界、结构先验和制造约束。

当前checkpoint的142维光谱输入不是“最多只能反演142个变量”的严格数学上限；但仅凭单角度R/T强度谱识别复杂长膜系，约束不足和非唯一性会更明显。必要时再讨论多角度、多偏振或相位等额外观测条件及相应训练。

本次0.4.3不修改20层生成上限、不改权重、不开展长膜系训练。
